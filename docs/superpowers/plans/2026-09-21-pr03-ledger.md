**Goal:** Enforce balanced immutable journals, once-only posting, reversal and independent balance verification.

**Architecture:** Scoped Java services call a single secured PostgreSQL posting function. Deferred constraints and limited runtime privileges protect data even from direct SQL; independent rebuilding scans entries without the posting path.

**Tech Stack:** Java 21, Spring JDBC transactions, PostgreSQL 16, Flyway, Testcontainers.

DB API: `platform.post_ledger(uuid org, uuid env, text currency, uuid provider, text event_key, text event_type, text source_domain, text source_ref, jsonb facts, jsonb entries, uuid reversal_of DEFAULT NULL) RETURNS uuid` (Journal ID). Entry JSON fields: `accountId`, `side` (`DEBIT`/`CREDIT`), `amount` (positive bigint). No untrusted dynamic identifiers. SQLSTATE `P0002` = scoped account/journal not found, `P0003` = evidence conflict, `23514` = invalid ledger data; other DB errors propagate for outer transaction handling.

Required query columns: ledger_account `(id,organization_id,environment_id,currency,account_purpose,source_domain,provider_account_id,balance_domain)`; financial_event `(id,organization_id,environment_id,currency,provider_account_id,event_key,event_type,source_domain,source_ref,facts)`; journal `(id,organization_id,environment_id,currency,financial_event_id,reversal_of_journal_id,sealed_at,created_at,status)`; journal_entry `(id,journal_id,ledger_account_id,organization_id,environment_id,currency,side,amount_minor,line_no)`; balance_projection `(ledger_account_id,organization_id,environment_id,currency,balance_minor,version)`.
