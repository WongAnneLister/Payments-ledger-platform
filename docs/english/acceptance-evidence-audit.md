## Audited gaps and update rule

The real-contract boundary is PARTIAL/BLOCKED where documented by PR05/06: selected Checkout/capture/refund/signature facts do not prove every real attempt, cancellation race, failed refund, dispute, payout or historical report. PR14's real read returned no payout objects; the object chain is NOT RUN. Bank matching throughout this audit uses SIMULATED_BANK_EVIDENCE.

Rows 36/37 need actual full performance and restore artifacts. Row 38 is PARTIAL because this English set and source-bound script exist but the PR20 combined demo has not been replayed at authoring. Its acceptance state cannot become PASS from file existence alone.

Keep these dimensions separate when results arrive: execution status, data completeness, product check result, source mode, exact code/input identity and raw artifact path. A failed target stays FAIL even if a later run succeeds. A missing capability remains BLOCKED or NOT RUN in its real scope even when a simulator passes. Update only the row supported by the new report and preserve the original artifact and frozen recorded column.
