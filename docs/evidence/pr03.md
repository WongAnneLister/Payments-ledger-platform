## 验收映射

**AC-V1-17 / I-01：** 正常收款 fixture 借 PSP 9700、借费用 300、贷收入 10000。Java 与数据库分别拒绝空/单行/失衡/非正金额/合计溢出；投影累计溢出回滚事件、凭证和分录。直接 SQL 提交不合法或未封存凭证失败。封存后 UPDATE/DELETE、单行追加和借贷平衡追加均失败。

**I-02 本次提交唯一性：** 8 个并发调用以同一事件键提交，只生成一张 Journal、一次余额变动。分录顺序改变不重复入账；同键修改事实或分录为 EVIDENCE_CONFLICT。事件与凭证一对一，孤立事件在提交时拒绝；外层业务事务失败，账本写入一起回滚。后续外部事件的发现完整性及双向覆盖扫描仍属于 PR10/PR15，不能用本次唯一性证明没有漏采外部事实。

**AC-V1-02 / I-07：** 跨组织/环境/币种/Provider 分录在服务或复合 FK/触发器层拒绝，科目用途与来源域不兼容也拒绝。合法的模拟银行和 Provider 混合分录可入账。真实运行角色不能直接写投影或配置科目；PSP 净余额允许为负。

**独立重建：** 从不可变分录以 BigInteger 独立累计，与投影在同一个 REPEATABLE READ 快照比较。故意通过隔离测试的管理连接把投影多加 1，报告残差 1，且不改变历史或自动修正投影。期初 Journal 只累计一次；外部期初模式必须有完整科目集合/来源/摘要/cutoff，不允许与 L-OPENING 混用。

**冲正：** 新事件 + 新关联凭证精确反转原分录，原始记录不变。相同冲正键返回原结果，换键第二次冲正被拒绝。
